# dodge game jam
dodge is a simple game i made using Turtle(python) where there is a little guy that has to dodge fruit falling from the sky (typical little ppl things). He has 3 lives and everytime he touches a fruit, he loses a life, lose all 3 lives, game over:(
To play: Download the zip, extract it, and click the PLAY_NOW.command file inside the folder while holding the control key to start the game instantly :) I made this code using Thonny with Turtle and this is my first time trying this and uploading so i hope i did it correctly and are able to play it!
